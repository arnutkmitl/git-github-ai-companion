# Chapter 8: Going Online with GitHub: Push, Pull, and Clone

Commands and code from this chapter, in the order they appear. Read the chapter for context before running anything.

## 8.1 Set up your account and connect your computer

Command:

```bash
git config --global user.email "12345678+alex-dev@users.noreply.github.com"
```

Command:

```bash
winget install --id GitHub.cli
brew install gh
```

Command:

```bash
gh auth login --scopes workflow
```

Command:

```bash
gh auth status
```

Command:

```bash
gh auth setup-git
```

Command:

```bash
git config --global pull.rebase false
```

## 8.3 Create a repository on GitHub and connect origin

Command:

```bash
git add README.md
git commit -m "Add a README with how to open and test the app"
```

Command:

```bash
gh repo create coffee-menu --public --source=. --remote=origin --push
```

Command:

```bash
git remote add origin https://github.com/alex-dev/coffee-menu.git
```

Command:

```bash
git remote -v
```

## 8.4 Send your work with push

Command:

```bash
git push -u origin main
```

## 8.5 clone: start from the copy on GitHub

Command:

```bash
git clone https://github.com/alex-dev/coffee-menu.git coffee-menu-2
```

## 8.6 fetch and pull: receive work from GitHub

Command:

```bash
git fetch
```

Command:

```bash
git log --oneline main..origin/main
git diff main...origin/main
```

Command:

```bash
git pull
```

## 8.7 When a push is rejected

Command:

```bash
git pull
```

Command:

```bash
git push
```

## 8.8 A README other people can use

File: Markdown:

```markdown
# SysAdmin Knowledge

A menu web page for a fictional coffee shop, used as the practice project in the book Git & GitHub for AI-Assisted Developers.

## How to open the app

Download or clone this project, then double-click index.html to open it in your browser. Nothing else needs to be installed.

## Features

- Shows drinks with prices and descriptions
- Sort-by-price button
- Dark mode toggle

## How to test

1. The menu shows all six items.
2. Click Sort by price: Thai Iced Tea ($2.50) appears first.
3. Click Toggle dark mode: the background turns dark and prices stay readable.
```
