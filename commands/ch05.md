# Chapter 5: Undo, Rewind, and Recover Broken Work

Commands and code from this chapter, in the order they appear. Read the chapter for context before running anything.

## 5.2 Unstage a file

Command:

```bash
git restore --staged app.js
git status
```

## 5.3 Discard changes to a file

Command:

```bash
git restore app.js
git status
```

Command:

```bash
git commit -m "Extend closing time to 18:00"
```

Command:

```bash
git restore .
```

## 5.4 Fix the last commit with --amend

Command:

```bash
git commit --amend -m "Extend closing time to 18:00 (6 p.m.)"
```

## 5.5 Cancel a commit with git revert

Command:

```bash
git log --oneline -3
```

Command:

```bash
git revert a70cddb
```

Command:

```bash
git log --oneline -4
```

## 5.6 Look at an old version of the code

Command:

```bash
git switch --detach c05652c
```

Command:

```bash
git switch main
```

## 5.7 The lab: git reset and git reflog

Command:

```bash
git reset --soft HEAD~1
git status
```

Command:

```bash
git commit -m "Undo the sort button tweak"
```

Command:

```bash
git reset --hard HEAD~3
```

Command:

```bash
git reflog -4
```

Command:

```bash
git reset --hard "HEAD@{1}"
```
