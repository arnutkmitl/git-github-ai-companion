# Chapter 10: Pull Requests and Code Review Before You Merge

Commands and code from this chapter, in the order they appear. Read the chapter for context before running anything.

## 10.1 Write an issue: work you can accept or reject

Command:

```bash
gh issue create --title "Add a Pastries category to the menu" --body "Details as in the example"
```

## 10.2 Work on a branch from the latest main

Command:

```bash
git switch main
git pull
git switch -c feature/snacks
```

Code: JavaScript:

```javascript
  { name: "Thai Iced Tea", price: 2.5, desc: "House recipe, less sweet on request", category: "Tea" },
  { name: "Croissant", price: 3, desc: "Real butter, baked fresh every morning", category: "Pastries" },
  { name: "Brownie", price: 4, desc: "Rich dark chocolate", category: "Pastries" }
```

Code: HTML:

```html
      <button data-category="Pastries">Pastries</button>
```

Command:

```bash
git add app.js index.html
git commit -m "Add a Pastries category with Croissant and Brownie"
git add README.md
git commit -m "Update the README for the Pastries category"
```

## 10.3 Push the branch and open a pull request

Command:

```bash
git push -u origin feature/snacks
```

Command:

```bash
gh pr create --base main --title "Add a Pastries category to the menu" --body "Closes #1"
```

## 10.4 The PR description: what changed and how it was tested

File: Markdown:

```markdown
Closes #1

What changed
- Added Croissant and Brownie in the Pastries category (app.js)
- Added a Pastries filter button (index.html)
- Updated the item count and test steps in the README

How it was tested
Ran every check under "How to test" in the README in Chrome.

Results
- The menu shows eight items
- The Pastries button shows Croissant and Brownie
- Sort, theme toggle, and the existing filters still work
```

## 10.6 Answer the review with more commits

Command:

```bash
git switch feature/snacks
```

Command:

```bash
git add app.js
git commit -m "Fix the Brownie price to $4.50 as in the issue"
git push
```

## 10.7 Choose how to merge, then clean up

Command:

```bash
gh pr merge --squash --delete-branch
```

Command:

```bash
git switch main
git pull
git fetch --prune
```

Command:

```bash
git branch -d feature/snacks
```

Command:

```bash
git branch -D feature/snacks
git log --oneline -3
```

## 10.8 Repository rules, and PRs opened by AI

Command:

```bash
gh pr checkout 2
```
