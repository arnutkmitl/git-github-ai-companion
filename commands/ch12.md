# Chapter 12: A Daily Workflow and Your First Steps into Teamwork

Commands and code from this chapter, in the order they appear. Read the chapter for context before running anything.

## 12.3 Build it as readable commits

Command:

```bash
git switch main
git pull
git switch -c feature/cart
```

Code: JavaScript:

```javascript
function addToCart(cart, item) {
  return [...cart, item];
}

function cartSummary(cart) {
  const total = cart.map((item) => item.price).reduce((a, b) => a + b);
  return { count: cart.length, total };
}
```

Command:

```bash
git add menu-logic.js tests
git commit -m "Add cart functions with tests"
```

Command:

```bash
git add app.js index.html
git commit -m "Add Add-to-cart buttons and a cart summary"
```

Command:

```bash
git add README.md
git commit -m "Update the README for the demo cart"
```

## 12.4 Review, test, and open a PR

Command:

```bash
git log --oneline main..feature/cart
git diff --stat main...feature/cart
node --test
```

Command:

```bash
git push -u origin feature/cart
gh pr create --base main --title "Add a demo cart"
```

## 12.6 Merge and release

Command:

```bash
git switch main
git pull
git fetch --prune
git branch -D feature/cart
```

Command:

```bash
git tag -a v1.0.0 -m "First delivered version: menu, filters, dark mode, and demo cart"
git push origin v1.0.0
```

Command:

```bash
git log --oneline --decorate -2
```

Command:

```bash
gh release create v1.0.0 --title "v1.0.0" --generate-notes
```

## 12.7 A bug after delivery

Command:

```bash
git switch main
git pull
git switch -c fix/empty-cart
```

Code: JavaScript:

```javascript
test("an empty cart has 0 items and a $0 total", () => {
  assert.deepStrictEqual(cartSummary([]), { count: 0, total: 0 });
});
```

Command:

```bash
git switch main
git pull
git tag -a v1.0.1 -m "Fix the Clear cart button"
git push origin v1.0.1
gh release create v1.0.1 --title "v1.0.1" --generate-notes
```

Command:

```bash
git log --oneline v1.0.0..v1.0.1
```
