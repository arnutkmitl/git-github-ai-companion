# Chapter 6: Branches: Try New Ideas Without Breaking What Works

Commands and code from this chapter, in the order they appear. Read the chapter for context before running anything.

## 6.1 A branch is a label that points at a commit

Command:

```bash
git branch
```

## 6.3 Create a branch with git switch -c

Command:

```bash
git switch -c feature/dark-mode
```

## 6.4 Build the feature in small commits

Code: CSS:

```css
body.dark {
  background: #1f1f1a;
  color: #eee8dc;
}
body.dark header h1 {
  color: #a9c46c;
}
body.dark #menu-list li {
  border-bottom-color: #44443a;
}
body.dark #menu-list small {
  color: #b8ad9c;
}
```

Command:

```bash
git add style.css
git commit -m "Add a dark theme color scheme"
```

Code: HTML:

```html
    <p>Open daily 7:00-18:00</p>
    <button id="theme-btn">Toggle dark mode</button>
```

Code: JavaScript:

```javascript
document.getElementById("theme-btn").addEventListener("click", () => {
  document.body.classList.toggle("dark");
});
```

Command:

```bash
git add index.html app.js
git commit -m "Add a dark mode toggle button"
git log --oneline -3
```

Command:

```bash
git switch main
```

## 6.5 Compare branches before merging

Command:

```bash
git log --oneline main..feature/dark-mode
```

Command:

```bash
git diff --stat main...feature/dark-mode
```

## 6.6 Merge with git merge

Command:

```bash
git switch main
git merge feature/dark-mode
```

Command:

```bash
git branch -d feature/dark-mode
```

Command:

```bash
git log --oneline --graph -6
```

## 6.7 Park work with stash, and throw away branches you don't need

Command:

```bash
git stash
```

Command:

```bash
git stash list
```

Command:

```bash
git stash pop
```

Command:

```bash
git switch main
git branch -d idea/big-text
```

Command:

```bash
git branch -D idea/big-text
```
