# Chapter 4: See What Changed: Diff, Log, and .gitignore

Commands and code from this chapter, in the order they appear. Read the chapter for context before running anything.

## 4.1 Read a diff piece by piece

Command:

```bash
git diff
```

## 4.2 Diffs before and after git add

Command:

```bash
git diff --staged
```

Command:

```bash
git add style.css
git diff
git diff --staged
```

Command:

```bash
git diff --stat
```

## 4.5 Look back: git show, git log, and git blame

Command:

```bash
git show --stat
```

Command:

```bash
git log --oneline --stat -2
```

Command:

```bash
git blame -L 3,3 app.js
```

## 4.6 .gitignore: keep files out of the repository

Command:

```bash
git check-ignore -v .env
```

## 4.7 When a file is already tracked

Command:

```bash
git rm --cached debug.log
git add .gitignore
git commit -m "Stop tracking debug.log"
```
