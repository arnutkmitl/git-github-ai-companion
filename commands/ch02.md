# Chapter 2: Install Git and VS Code and Open Your First Project

Commands and code from this chapter, in the order they appear. Read the chapter for context before running anything.

## 2.1 Files, folders, and where your terminal is

Command:

```bash
pwd
ls

```

## 2.2 Install Git and VS Code

Command (PowerShell):

```powershell
winget install --id Git.Git -e --source winget
```

Command:

```bash
git --version
```

Command:

```bash
brew install git
```

Command:

```bash
sudo apt update && sudo apt install git
sudo dnf install git
```

## 2.3 Check the installation

Command:

```bash
git --version
```

## 2.4 Set your name, email, and default branch

Command:

```bash
git config --global user.name "Alex Rivera"
git config --global user.email "alex@example.com"
git config --global init.defaultBranch main
git config --global core.editor "code --wait"
```

Command:

```bash
git config --global --list
```
