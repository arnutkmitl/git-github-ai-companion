# Chapter 7: Merge Conflicts Without the Panic

Commands and code from this chapter, in the order they appear. Read the chapter for context before running anything.

## 7.2 Create a conflict you can repeat

Command:

```bash
git switch -c update/latte-price
```

Code: JavaScript:

```javascript
  { name: "Latte", price: 4.5, desc: "Silky steamed milk" },
```

Command:

```bash
git add app.js
git commit -m "Raise the latte price to $4.50"
```

Command:

```bash
git switch main
git switch -c update/latte-desc
```

Code: JavaScript:

```javascript
  { name: "Latte", price: 5, desc: "Whole milk, double shot" },
```

Command:

```bash
git add app.js
git commit -m "Switch the latte to a double shot"
```

Command:

```bash
git switch main
git merge update/latte-price
```

Command:

```bash
git merge update/latte-desc
```

## 7.5 Check the result, then finish the merge

Command:

```bash
git diff --check
```

Command:

```bash
git add app.js
git status
```

Command:

```bash
git diff --staged
```

Command:

```bash
git log --oneline --graph -4
```

Command:

```bash
git branch -d update/latte-price update/latte-desc
```

## 7.6 Abort with git merge --abort

Command:

```bash
git merge --abort
```
